AudioX: Video to MP3 Extractor

Audio Extractor Flutter & FFmpeg Batch Queue 100% On-Device & Private

Extract audio from video. Save it. Done. AudioX is a focused, single-purpose Android utility built with Flutter and native FFmpeg that converts local device videos and shared video links into clean 192 kbps MP3s—with Share Sheet launch, in-app playback preview, custom renaming, and background batch extraction directly to Music/AudioX/.

VIEW ON GitHub Support & Feedback

Core Audio Extraction Capabilities

Share-First Android Workflow

Registered for ACTION_SEND and ACTION_SEND_MULTIPLE across video files, streams, and URLs. Share from your Gallery, File Manager, or browser to jump straight into extraction.

Native On-Device FFmpeg Encoding

Extracts audio streams offline via libmp3lame at 192 kbps stereo, stripping bloated container metadata while writing clean ID3v2.3 tags for universal player compatibility.

Batch Queue & Background Service

Queue up to 50 videos at once with sequential low-memory processing, automatic transient error retries, and an Android foreground service with live progress notifications.

In-App Audio Preview & Rename

Audition extracted tracks immediately with play, pause, seek bar scrubbing, and duration readouts powered by just_audio, then customize filenames before saving.

Scoped Storage & Collision Safety

Publishes MP3 files atomically to Music/AudioX/ using Android's MediaStore.Audio.Media with automatic (1), (2) deduplication and zero broad storage permissions.

Modular URL Resolver Pipeline

Resolves direct media links (.mp4, .webm, .mkv) and OpenGraph video metadata with streaming byte progress, cancellation support, and clear DRM platform detection.

Technical Specifications & Details

Developer Silverbyte Studio (SBS Apps)
Tech Stack Flutter (Dart 3), Kotlin Platform Channels, FFmpeg (libmp3lame), just_audio
Target Platform Android 10+ (minSdk 29 / compileSdk 37, Scoped Storage & MediaStore)
Output Format MP3 (192 kbps stereo, ID3v2.3 tags, saved to Music/AudioX/)
Source Code github.com/hrud09/AudioX
Data Privacy Model 100% On-Device Local Processing (Zero accounts, analytics, or cloud uploads)
